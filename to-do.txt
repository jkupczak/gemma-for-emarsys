### Image Zoom

In all three tabs of the Image Picker, I want the user to be able to adjust the zoom level of the image thumbnails that get displayed when they are using Grid View. 

- To display the lowest zoom level, the thumbnails should use `object-fit: contain;` in the Recent Images and Favorite Images tabs where we display thumbnails using the <img> tag. Meanwhile, the Media Database tab relies on `background-image`, so there we need to use `background-size: contain`. Lets call that zoom level 1.

- When the user increases the zoom level, it should be increased relative to the available space. For example, if the container that the image sits in has an aspect ratio of 1/1 and the image itself also has an aspect ratio of 1/1, the increase in size for zoom level 2 should be minimal. Conversely, if the image aspect ratio is 10/1, then a level 2 zoom should be more substantial by comparison.

- Lets implement 5 levels of zoom.

- Use the HTML entity for U+F048 as the icon text string for zooming out. Use this for the icon attribute: `ac-icon_zoomout`
- Use the HTML entity for U+F047 as the icon text string for zooming in. Use this for the icon attribute: `ac-icon_zoomin`

Here is the code for the icons:

<e-icon icon="{icon}">
  <div aria-hidden="true" class="e-icon-wrapper">
    <div class="e-icon">{html-entity}</div>
  </div>
</e-icon>

Place the controls in `.gem-image-picker-controls` right before `.gem-img-picker-cols-control`.

When the user can't zoom in or out any further, the icon for that action should be dimmed and disabled.
Zoom level should be synced across the Media Database, Recent Images, and Favorite Images tabs.
Zoom level should be logged in storage so that it will be remembered across sessions, page loads, and other browser tabs.

### "Title" hiding

Emarsys's link edit dialog features an input field for the user to specify text to be used in the links `title` attribute. The `title` attribute is considered poor for accessibility. So by default I've added some CSS to the `styles.css` file that hides that field from the user to discourage its use. 

I want to add a toggle to the Settings panel so that users can override this. Add it to the XXX section and add this sub-label description underneath it: "Titles on links are considered poor for accessibility. Gemma hides the field by default to dissuade users from using it. Toggle this on to restore its visibility."

The default value for the toggle should be off which is equal to the CSS hiding the field. Toggling it to on should stop the CSS from hiding it. I've already added the appropriate CSS to the `style.css` file. It looks like this: `[for="input-title"], cb-personalizable-input-with-context { display:none }`.
